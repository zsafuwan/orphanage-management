Persona Perspectives

Role-Based Access & Perspectives

The HopeHaven system is strictly segmented into dedicated views optimized for each stakeholder's responsibilities.

Sister Sarah

Executive Director of Sanctuary Operations
Highest Authority

Primary Governance Responsibilities:

Treasury Oversight: Manage liquid bank reserves (RM 148,350) and 6.2 months operating runway.
Requisition Authorization: Sign-off on staff inventory requisitions and emergency clinical purchases.
Medical Health Watch: Real-time clinical watch on active sickness, clinic trips, and allergies.
Education Endowments: Track student GPA, school attendance, and tuition grant funding.
Staff RBAC: Register new caregivers, assign wards, and manage personnel credentials.

Nurse Mary Jenkins

Senior Residential Caregiver & Clinical Lead
Verified Healthcare Staff

Daily Operational Duties:

Daily Clinical Triage: Log morning temperature checks, medication schedules, and dietary restrictions.
Supply Requisitions: Submit restock requests for children nutrition, diapers, and first-aid supplies.
Ward Welfare Logs: Record incident reports, homework assistance, and bedtime roll-calls.
Duty Roster: Coordinate shift handovers and supervise volunteer activity groups.
Staff Profile: Manage personnel credentials, safeguarding certifications, and duty calendar.

System Administrator

Central Operations & System Auditor
System Root

System Management Responsibilities:

User Account Provisioning: Onboard staff, reset 2FA / passwords, and audit login sessions.
Audit Logs & Compliance: Enforce child privacy compliance (PDPA / Child Act 2001).
Database Backups: Manage MySQL relational backups and cloud document store sync.
System Configuration: Set automated email triggers, SMS alerts, and donation gateway keys.

Relational Entities

Database Architecture & Entity Relationships

Normalized schema structure powering the sanctuary operations, requisitions, and welfare auditing.

children Table
  • PK id bigint
  • registration_number varchar(50)
  • full_name varchar(255)
  • birth_date date
  • ward_dormitory enum(A, B)
  • jkm_custody_ref varchar(100)
  • FK assigned_nurse_id bigint
  • welfare_status varchar(50)
medical_records Table
  • PK id bigint
  • FK child_id bigint
  • diagnosis varchar(255)
  • allergies text
  • appointment_date datetime
  • hospital_clinic varchar(255)
  • cost_estimate decimal(10,2)
  • cleared_by_director boolean
inventory_requests Table
  • PK id bigint
  • FK requested_by bigint
  • item_name varchar(255)
  • category varchar(100)
  • quantity int
  • estimated_total decimal(10,2)
  • priority enum(routine, urgent)
  • status enum(pending, approved)
  • FK authorized_by bigint
donations Table
  • PK id bigint
  • receipt_number varchar(50)
  • donor_name varchar(255)
  • donor_ic_ssn varchar(50)
  • amount decimal(10,2)
  • earmarked_fund varchar(100)
  • payment_gateway_ref varchar(100)
  • tax_exempt_sent boolean
users Table
  • PK id bigint
  • name varchar(255)
  • email varchar(255)
  • role enum(director, staff, admin)
  • staff_id_code varchar(50)
  • duty_shift varchar(50)
  • two_factor_secret text
  • active_status boolean
Engineering Standards

Architected for reliability, data security, and long-term maintainability.

Compliant with Child Act 2001 and Personal Data Protection Act. Sensitive medical and adoption data protected with role-based policies.
